# KEYMAP: e2s_mp 五键、手势与逐屏矩阵

屏上键只用符号：`◀ ▶ ▭ ○ ×`。`MENU`、`OK`、`FUNC`、`PREV`、`NEXT`
是固件内部标识，不是屏显文案，屏上也不会出现英文键名。

物理按键按机身从左到右、从上到下依次为：**左 (`◀`, GPIO2) / 右 (`▶`, GPIO6) / 胶囊菜单 (`▭`, GPIO4) / 确认 (`○`, GPIO8) / 取消 (`×`, GPIO7)**。底栏中文动词是用户看到的提示（`main/mp_hints.c`）。

---

## 1. 五键

| 物理键 | 固件标识 | GPIO | 屏显符号 | 含义 | 事件 | 证据 |
|---|---|---|---|---|---|---|
| 左 | `KEY_PREV` | 2 | `◀` | 上、左、上一页、减 | DOWN/CLICK/LONG/REPEAT | 结合原厂 1.3.739 反汇编 `KeyInit` |
| 右 | `KEY_NEXT` | 6 | `▶` | 下、右、下一页、加 | 同上 | 同上（反汇编 `42025521` 等） |
| 胶囊 | `KEY_FUNC` | 4 | `▭` | 菜单（READ 进书籍信息）、整屏刷新、长按快捷背光浮窗（仅 E2S 生效） | DOWN/CLICK/LONG | 同上 |
| ○ | `KEY_OK` | 8 | `○` | 打开、确定、刷/重试；长按锁屏、解锁或提交 | DOWN/CLICK/LONG | 真机实测 |
| × | `KEY_MENU` | 7 | `×` | 返回、取消、退出阅读；长按回时钟或退 DEBUG | DOWN/CLICK/LONG | 真机实测 |

- GPIO 2/4/6/7/8 低有效，内部上拉（`board.h:46-54`、
  `components/input/input_keys.c`）。
- 键帽放在 14×14 布局槽里，没有方框外框。返回/取消键是 10×10 对称 `×` 符号，
  胶囊菜单是 12×6 圆角空心胶囊 `▭`，OK 是 10×10 圆环 `○`。
- 屏上不会出现 `F`、`L`、`R` 这类 Miaopaper 键名，也不会出现
  `MENU`、`OK`、`FUNC`。

### 1.1 事件与时序

| 项 | 值 | 说明 |
|---|---|---|
| 轮询 | 20 ms | `input_keys.c` |
| 去抖 | 60 ms | 连续 3 次采样一致 |
| 短按 | 按下到松开小于 1.0 s | 松开时发 `KEY_EV_CLICK` |
| 长按 | 1.0 s，从去抖后起算，物理约 1.06 s | 每次按下只发一次 `KEY_EV_LONG`，LONG 后松手不再发 CLICK |
| 连发 | 不使用 | `KEY_EV_REPEAT` 一律忽略 |
| OK 双击窗口 | 350 ms | 只对 OK；READ 上回上一页，其他屏无动作 |

- 五键只在 CLICK 和 LONG 上动作。`KEY_EV_DOWN` 不产生动作。
- 非 OK 键的 DOWN 会取消待发的 OK 单击。OK 自己的 DOWN 只用于
  `restore_key_ok`。
- `input_inject()` 对 PREV 和 NEXT 注入 DOWN，不能驱动本状态机。自测直接调
  `mp_app_key(id, KEY_EV_CLICK, now_ms)`。

### 1.2 OK 的 350 ms 多击门

```
收到 OK CLICK：
  if (pending_ok && now - pending_ok_ms <= 350) {
      pending_ok = 0;                 // 双击
      if (screen == READ) 上一页();
      // 其他屏无动作，这对 CLICK 被吞掉
  } else {
      pending_ok = 1; pending_ok_ms = now;
  }
每轮循环：if (pending_ok && now - pending_ok_ms > 350) {
      pending_ok = 0; 执行本屏 OK 单击动作();
  }
收到 OK LONG：pending_ok = 0（长按优先）
任何非 OK 键或切屏：pending_ok = 0
```

- 必须全局延迟，否则 LOCK 上连按两下会先解锁，再落到下一屏继续动作。
- 代价是所有屏的 OK 单击都慢约 350 ms。这是 Miaopaper 的手感。
- BLE `0x21` 关闭书时也清 `pending_ok`。

## 2. 逐屏矩阵

符号：`—` 表示无动作，`▸屏` 表示切到该屏。“短”是 CLICK，OK 经过
350 ms 门；“长”是 LONG；“双”是两次 OK CLICK 间隔不超过 350 ms。
除 READ 外，所有屏的“双”都是无动作并吞掉这对单击。

### 2.1 CLOCK

| 键 | 短 | 长 | 双 |
|---|---|---|---|
| `◀` PREV | `▸SETTINGS` | `▸SETTINGS` | — |
| `▶` NEXT | `▸SELECT`，空库进 `EMPTY` | `▸SELECT`，空库进 `EMPTY` | — |
| `○` OK | `▸SELECT`，空库进 `EMPTY` | `▸LOCK` | — |
| `×` 取消 | 无动作 | 整屏刷新 | — |
| `▭` 胶囊 | 整屏刷新 | 弹出快捷背光框 | — |

### 2.2 SELECT

| 键 | 短 | 长 | 双 |
|---|---|---|---|
| `◀` PREV | 光标上移，越顶到末尾 | — | — |
| `▶` NEXT | 光标下移，越底回 0 | `▸CLOCK` | — |
| `○` OK | 打开选中书 | `▸LOCK` | — |
| `×` 取消 | `▸CLOCK` | `▸CLOCK` | — |
| `▭` 胶囊 | 整屏刷新 | 弹出快捷背光框 | — |

### 2.3 READ

| 键 | 短 | 长 | 双 |
|---|---|---|---|
| `◀` PREV | 上一页 | — | — |
| `▶` NEXT | 下一页 | 保存进度后 `▸CLOCK` | — |
| `○` OK | 下一页，350 ms 后执行 | `▸LOCK` | 上一页 |
| `×` 取消 | 保存进度、`▸SELECT` | 保存进度后 `▸CLOCK` | — |
| `▭` 胶囊 | `▸BOOK_INFO` | 弹出快捷背光框 | — |

阅读页没有底栏，底部是 2 px 进度条。短按胶囊菜单进书籍信息，短按 `×` 返回书库，长按 `×` 或 `▶` 回时钟。

### 2.4 SETTINGS

| 键 | 短 | 长 | 双 |
|---|---|---|---|
| `◀` PREV | 光标上移，环绕，跳过存储行 | `▸CLOCK` | — |
| `▶` NEXT | 光标下移，环绕，跳过存储行 | — | — |
| `○` OK | 切换开关、循环值；背光进 `▸BACKLIGHT`；时间设置进 `▸TIME_SET`；关于进 `▸ABOUT`；恢复原厂固件进 `▸RESTORE` | `▸LOCK` | — |
| `×` 取消 | `▸CLOCK` | `▸CLOCK` | — |
| `▭` 胶囊 | 整屏刷新 | 弹出快捷背光框 | — |

设置项按硬件探测自适应：E2S（有背光）共 7 行；E2（无背光）自动隐藏背光项（共 6 行）。窗口显示 4 行：

| E2S 行号 | 项 | 右侧 | 选中后 OK |
|---|---|---|---|
| 0 | 蓝牙 | 胶囊开关 | 翻转 `ble_enabled`，立即 `mp_ble_adv()` 并存盘 |
| 1 | 锁屏 | `3分钟` | 循环 1/2/3/5 分钟，即 60/120/180/300 秒 |
| 2 | 锁屏展示 | `阅读数据` | 切换 `阅读数据` 和 `锁屏图`；没有有效锁图时进 NO_LOCK_IMG |
| 3 | 背光 | `关` / `1档`..`3档`（无背光 E2 隐藏） | 进 `▸BACKLIGHT` 滑条设置页 |
| 4 (E2=3) | 时间设置 | chevron (`>`) | 进 `▸TIME_SET` 向导 |
| 5 (E2=4) | 关于 | chevron | 进 `▸ABOUT`（内含存储空间 `MB`） |
| 6 (E2=5) | 恢复原厂固件 | chevron | 进 `▸RESTORE`，确认页长按提交 |

选中行是微圆角整行反色条。4 行装不下时右侧出现滚动条，开关在最右侧。
快刷和全刷不再出现在设置页，内部刷新策略由默认值和 BLE 设置维护。

### 2.4.1 BACKLIGHT（背光设置页）与快捷背光弹窗

- **硬件门控**：仅开机探测到 AW2023 背光芯片的设备（E2S）启用。无背光设备（E2）既不展示设置项，在所有页面长按胶囊菜单键 `▭` 也不会触发快捷背光浮窗（静默无动作）。
- `BACKLIGHT`：`◀`/`▶` 实时调节 `0..3` 档背光；`○` 确认保存并回 `SETTINGS`；`×` 取消恢复进入前档位并回 `SETTINGS`；页面内展示 `长按[▭]快速调整背光`；长按 `○` 不锁屏。
- **快捷背光弹窗**：在时钟、书库、阅读、设置等常规屏长按胶囊菜单键 `▭` 弹出叠加滑条窗；`◀`/`▶` 实时调整 `0..3` 档；短按 `○` 确认保存并关闭弹窗；按 `×` 或 `▭` 取消恢复原档位并关闭弹窗。

### 2.8 TIME_SET

| 键 | 短 | 长 | 双 |
|---|---|---|---|
| `◀` PREV | 当前字段减 1，回绕 | — | — |
| `▶` NEXT | 当前字段加 1，回绕 | — | — |
| `○` OK | 下一步；最后一步提交并 `▸TIME_DONE` | 无动作，不锁屏 | — |

| 键 | 短 | 长 | 双 |
|---|---|---|---|
| `○` OK | 无动作 | 提交，仅 `restore_armed && restore_key_ok` 时 | — |

## 3. 底栏

一组由前缀中文、1..2 个键帽和后缀中文组成。组内间距 1 px，两组默认 36 px，三组默认 14 px。
所有屏按实际总宽水平居中。超出 234 px 时压缩组距或丢弃尾组，不换行。

| 屏 | 组 1 | 组 2 | 组 3 |
|---|---|---|---|
| CLOCK | `[◀]设置` | `[▶]书库` | — |
| SELECT | `[◀][▶]选择` | `[○]打开` | `[×]返回` |
| READ | 无底栏，底部是 2 px 进度条 | | |
| SETTINGS | `[◀][▶]选择` | `[○]确定` | `[×]返回` |
| BACKLIGHT | `[◀][▶]调整` | `[○]确定` | `[×]取消` |
| ABOUT | `[×]返回` | — | — |
| BOOK_INFO | `[◀][▶]选择` | `[○]确定` | `[×]返回` |
| JUMP | `[◀][▶]调整` | `[○]跳转` | `[×]取消` |
| TIME_SET | `[◀][▶]调整` | `[○]下一步` | `[×]取消` |
| DELETE | `长按[○]删除` | `[×]取消` | — |
| TIME_DONE | 无 | — | — |
| LOCK | 无；锁屏图不叠字，统计页和提示页自带 `长按[○]解锁` | | |
| LOW_BATT | 无；整屏显示空电池感叹号 + `电量耗尽` / `请充电` 后深睡 | | |
| EMPTY | `[○]刷新` | `[×]返回` | — |
| ERROR | `[○]重试` | `[×]返回` | — |
| RESTORE | `长按[○]恢复` | `[×]取消` | — |
| NO_LOCK_IMG | `[×]返回` | — | — |

动词只有这些：`设置 书库 选择 调整 打开 确定 下一步 跳转 返回 刷新
重试 取消 恢复 删除`。`长按` 是前缀，`解锁` 只出现在锁屏页。

## 4. 特殊流程

### 4.1 锁屏、自动省电与解锁

- 进入：普通屏 OK 长按；CLOCK、SELECT、READ、SETTINGS、ABOUT、EMPTY
  的 FUNC 长按；到锁屏超时，档位为 1/2/3/5 分钟，默认 3 分钟。
  ERROR 屏的 FUNC 长按不锁屏。
- 不自动锁：BLE 已连接、上传中、DEBUG、LOCK、RESTORE、BOOK_INFO、JUMP、
  DELETE、TIME_SET、TIME_DONE。
- TIME_SET、JUMP、TIME_DONE 的 OK 长按不触发锁屏。
- 锁屏进入一律 `scene_commit(force_full=1)`。锁屏图只画图，不叠文字。
- 蓝牙自动关断：锁屏后持续 2 分钟（120 s）无 BLE 通信自动关闭蓝牙；亮屏/日常超过
  10 分钟（600 s）未使用蓝牙也会自动关闭蓝牙。
- 锁屏深度休眠与无感恢复：锁屏且蓝牙关闭后（宽限 10 s，若锁屏期刚自动关蓝牙则宽限
  2 s）自动落盘进度、保留当前画面并进入 Deep Sleep。此时短按任意键不会点亮屏幕
  （防口袋误触）；长按 `○` 确认键 500 ms 即可直接恢复原阅读页或时钟页。
- 阅读统计页和锁屏图都支持长按 OK 解锁。

### 4.2 恢复原厂

- 入口只有 SETTINGS 第 8 项，短按 OK 进入。ABOUT 上 OK 长按仍是锁屏。
- 确认页显示 `重启后生效`，底栏为 `长按[○]恢复` /
  `[×]取消`。
- 成功后显示 `已切换 / 3秒后重启`，3 s 后 `esp_restart()`。失败不重启。
- 切到原厂是单向操作。要回 mp，只能在原厂运行时把 mp 烧到当前活动槽。

### 4.3 DEBUG

- BLE `0x40` 进入 DEBUG：先画一条全宽横线，之后不再重绘，不响应其他键，
  不自动锁屏。30 s 超时，每次 `0x40` 续期并重画。
- 退出：`0x41`、长按 MENU、30 s 超时。三者任一都回 CLOCK 并整屏刷新。
- 锁屏时 `0x40` 被白名单拒绝。上传期间 `0x40` 仍会进入 DEBUG。

### 4.4 上传

- 上传期间普通按键和场景重绘被抑制，不采样电量，不自动锁屏。
  BLE `0x40` 是例外，仍会进入 DEBUG 并出帧。
- 上传时统计字数：GB2312 全角按 1 字，ASCII 按 1 字节，空白不算。
  结果写入目录项 `0x1E..0x1F`，单位为 1024 字，供 BOOK_INFO 显示。
- `0x12` 成功：SELECT 屏立即重绘，EMPTY 屏进 SELECT。
- `0x21` 关书：保存进度，回 CLOCK，整屏刷新。

## 5. 未验证与推断

- GPIO7=MENU、GPIO8=OK 的映射来自 `board.h:47` 的真机记录，本次没有复测。
  PREV(2)、NEXT(4)、FUNC(6) 仍是推断，第一次上机必须先验证。
- 本文矩阵来自 `PORT_SPEC.md` 和当前 `mp_app.c` 的
  `on_click`、`on_long`、`on_ok_click`、`on_ok_long`，没有做逐键手测。
- 350 ms 门、双击、长按 NEXT 退出阅读等手感项没有在硬件上计时验证。
