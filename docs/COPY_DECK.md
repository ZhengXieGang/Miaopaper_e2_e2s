## 1. 文案规范

### 1.1 十条规则

1. **短**：状态栏标题 ≤ 96 px；正文行 ≤ 234 px；阅读行 ≤ 246 px。
2. **直**：动词开头或名词短语；不用被动句、不用从句。
3. **具体**：给数字、给动作。`3分钟` 而不是 `锁屏时间`；`重启设备` 而不是 `请稍后重试`。
4. **一句说清**：标题说"这是什么"，正文说"发生了什么/怎么办"；不写两句同义话。
5. **不重复标题**：标题是 `设置`，正文不再出现"设置"；标题是 `删除本书`，正文不写"删除本书"。
6. **不解释常识**：不写"按左右键移动""按确定键继续"这类。
7. **不寒暄、不鼓励**：没有"恭喜""感谢""再见"。
8. **错误页 = 什么错 + 怎么办**：两行，第一行现象，第二行动作。不写错误码、不写原因链。
9. **恢复页 ≤ 3 行**。
10. **数字与单位不加空格**：`3分钟`、`12.4/118.5MB`、`11:30`；标签与数字之间保留一个空格（`字数 1.2万`）。

### 1.2 禁止词（出现在任何字符串字面量里即验收失败）

```
请   是否   确认要   操作成功   操作失败   正在   温馨提示   注意
```

另外禁止（英文键名/系统措辞）：

```
MENU  OK  FUNC  PREV  NEXT  Settings  Back  Locked  Loading  Error
快刷  全刷
```

- `OK` 只允许作为**标识符**（`MP_ST_OK`）出现，不得进字符串。
- 屏上不得出现 `F`/`L`/`R` 这类键名；键一律用键帽符号。
- **不出现"快刷/全刷"**：这是内部刷新策略，用户不需要理解；设置页不再暴露这两个开关。

### 1.3 允许的英文（白名单）

| 词 | 用途 | 位置 |
|---|---|---|
| `Miaopaper` | 产品名 | ABOUT |
| `E2S` / `E2` | 型号（按背光芯片自动探测显示） | ABOUT |
| `GB` | 容量单位 | SETTINGS 存储行 |
| `MB` / `KB` / `B` | 文件大小单位 | BOOK_INFO |
| `MPP_` | BLE 广播名（**不上屏**） | — |

除以上，屏上一律中文。

### 1.4 标点

- 中文逗号句号用全角 `，` `。`；不用 `！`、`~`、`…`、`·`。
- 行末不加标点（标题、设置项、按钮提示）。
- 正文行内可以有 `，` `。`（书籍内容除外，那是原文）。
- 不写书名号（书名原样显示）。

### 1.5 宽度算法

UI 的 ASCII 用 **Inter Regular 16 px**（比例宽），中文用 HZK16（16 px/字）。
`sim/` 的像素哈希是真源；写文案时用下面的保守预算：

- 状态栏 left ≤ 96 px；mid ≤ 38 px；时间居中，宽约 36 px；
- 内容行 ≤ 234 px；阅读行 ≤ 246 px；
- 底栏一组 ≤ 82 px，一行 ≤ 234 px；
- 电池内百分比用 5×7 数字，不占正文宽度。

`tools/check_copy.sh` 仍按 8 px/ASCII 做保守门（实际 Inter 更窄），命中只说明需要复核，不一定溢出。

## 2. 逐屏逐字文案

图例：**编码** `U` = UTF-8 源串（`mp_ui_text`：ASCII 走 Inter，中文走 HZK）；
`G` = GB2312 原始字节（`mp_text_draw(enc=MP_ENC_GB2312)`）；
`A` = ASCII 原始字节（`mp_text_draw(enc=MP_ENC_ASCII)`，Dialog 比例宽）；
`I` = Inter Clock 66 px（大号数字）。

> 状态栏固定结构：左标题 / 居中时间 / 蓝牙符文 / 内嵌百分比的电池。
> `time_valid=0` 的屏不画时间（CLOCK / JUMP / TIME_SET / RESTORE）。

## 3. 动态格式串

### 3.1 状态栏日期（CLOCK）

```c
snprintf(buf, sizeof buf, "%02u-%02u %s", month, day, week_str);
```

| 字段 | 取值 | 例 |
|---|---|---|
| `month` | 1..12，两位补零 | `11` |
| `day` | 1..31，两位补零 | `25` |
| `week_str` | 周一/周二/周三/周四/周五/周六/周日，由 `week`（1..7）查表 | `周三` |

不显示年份（年份在 ABOUT 与 TIME_SET）。

### 3.2 状态栏时间

```c
snprintf(buf, sizeof buf, "%02d:%02d", hour, min);
```

未同步时用默认 2026-01-01 00:00 → `00:00`；`0xDD` 或 TIME_SET 之后为真实时间。

### 3.3 书库计数

```c
snprintf(buf, sizeof buf, "书库 %u/8", done_count);   /* 书库 0/8 .. 书库 8/8 */
```

### 3.4 存储容量

```c
/* total/free 单位：字节；按 MiB 先算到 0.1 MB 再拆整数/小数，避免 %f（置于关于页） */
snprintf(buf, sizeof buf, "%u.%u/%u.%uMB",
         used_tenths / 10, used_tenths % 10, total_tenths / 10, total_tenths % 10);
```

- `tenths = (bytes * 10 + MB/2) / MB`，`MB = 1024*1024`（匹配 128 MB 内置 SD NAND 实际容量）。
- `mp_store_space()` 失败 → `不可用`。

### 3.5 BOOK_INFO 元信息

```c
snprintf(buf, sizeof buf, "字数 %s\t进度 %u%%\t大小 %s", words, pct, size);
```

- `words`：`%u.%u万`（≥1 万字）或 `%u`；`--` 表示旧目录项没有计数。
- `size`：`%u.%uMB` / `%uKB` / `%uB`（1024 进制）。
- 三段由 UI 按 `\t` 分隔并均分间隔。

### 3.6 百分比 / 跳转

```c
snprintf(num, sizeof num, "%u", pct);   /* JUMP 用 Inter_Num_26 数值 + Inter_UI_16 '%' + 进度滑块，0..100 */
```

### 3.7 ABOUT 版本/构建

```c
snprintf(buf, sizeof buf, "固件 %u.%u.%u", READER_VERSION_MAJOR, MINOR, PATCH);
/* 构建行用编译期常量，不用 __DATE__（可复现构建） */
#define MP_BUILD_DATE "2026-11-25"
snprintf(buf, sizeof buf, "构建 %s", MP_BUILD_DATE);
```

## 6. 自检（实现后必须跑）

```sh
sh tools/check_copy.sh            # 禁止词 + 英文键名 + SD 措辞 + 长度
cd sim && make && ./build/sim_mp --check   # 27 帧像素哈希 + 版式断言
```

脚本做四件事：

1. 扫 `main/*.c` 的所有 `"…"` 字面量（去掉注释、跳过 `#include`/`_Static_assert`），命中 §1.2 的禁止词 → 报文件:行 + 词。
2. 命中英文键名 `MENU|OK|FUNC|PREV|NEXT|Settings|Back|Locked|Loading|Error`（整词）→ 报。
3. 命中 `插卡|SD 卡|SD卡|内存卡` → 报。
4. 宽度：8 px/ASCII、16 px/非 ASCII；普通行（含中文字面量）≤234，状态栏标题 ≤112，底栏动词 ≤32。日志与带 `%` 的格式串不参与宽度检查。

另外人工核对：

- 每屏的实际渲染与 `docs/COPY_DECK.md` §2 的表格**逐字**一致。
- 文案宽度列与 `sim` 实际像素一致（改字必须重跑 `--check`）。
- 屏上不得出现"快刷/全刷"，也不得出现面板型号。
